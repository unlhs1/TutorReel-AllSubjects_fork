# 口语化配音规范（spoken-guide）

`spokenText` 是用于 AI 语音合成（TTS）的逐字稿。它必须**像真人老师讲课一样口语化**，让语音引擎能自然朗读。

## 硬性禁止
- ❌ 禁止出现数学符号缩写：`^`、`*`、`/`、`=`、`∑`、`∫`、`lim`、`→`、`∞`、`≤`、`≥`、`√`
- ❌ 禁止 LaTeX 命令：`\frac`、`\lim`、`\sum`、`\to`、`\leq`
- ❌ 禁止下标写法：`x_1`、`dp[i]`、`x1`
- ❌ 禁止英文公式夹杂：`f(x)` 不能直接念

## 必须的转换
- `x^2` → "x 的平方"；`x^3` → "x 的三次方"
- `x_1`、`x_2` → "x 一"、"x 二"（或 "第一个 x"、"第二个 x"）
- `lim(x→0)` → "当 x 趋近于 0 时"
- `∑_{k=0}^{n}` → "从 k 等于 0 到 n 的求和"
- `∫_a^b f(x)dx` → "从 a 到 b 对 f x 的定积分"
- `≤` → "小于等于"；`≥` → "大于等于"
- `∞` → "无穷大"
- `√x` → "根号 x"
- `π` → "派"
- `≈` → "约等于"
- `e` → "自然常数 e" 或 "e"
- `×` → "乘以"
- `λ` → "lambda" 或 "拉姆达"
- 分数 `a/b` → "a 分之 b"（如 1/2 → "二分之一"）

## 风格要求
1. 语气自然、口语化，可适度加入"那么"、"对吧"、"你看"、"接下来"等连接词。
2. 每步 30-80 字，讲清楚这一步在做什么、为什么。
3. 用完整的句子，不要用提纲式短语。
4. 数字用中文读法或自然读法：0.005 → "零点零零五"，10000 → "一万"，70 → "七十"。

## 示例
❌ 差：`lim(x->0) sinx/x = 1，x^2 是偶函数`
✅ 好：`当 x 趋近于 0 时，sine x 比上 x 的极限等于一。另外，x 的平方是一个偶函数。`
