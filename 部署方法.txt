# TutorReel 部署方法

> 头部声明：本文档写给任何 AI Agent 或开发者。按顺序照做即可完成部署、启动、验证。遇到问题先看文末"常见坑"，不要跳过步骤 5 和 7 的验证。

## 0. 这个项目是什么

把题目图片或题目文字，自动转成带图解、公式推导、配音的讲解短视频，可导出 MP4。
后端是 Express + Node，前端是 React + Vite，视频渲染用 Remotion，AI 讲解用 DeepSeek，OCR 识别题目图用通义 DashScope。

## 1. 环境要求

- Windows 10（本机开发验证环境）
- Node.js 18+（本机为 v20.18.0）
- Microsoft Edge 浏览器（Remotion 渲染视频帧时必须，路径见步骤 7）
- 不需要 Python，不需要 GPU，不需要数据库
- 需要两个 API Key（见步骤 3）

## 2. 安装依赖

在项目根目录（含 package.json 的目录）执行：

```bash
npm install
```

## 3. 配置环境变量

```bash
cp .env.example .env
```

编辑 `.env`：

- `OPENAI_API_KEY`：DeepSeek 的 API Key，必填。获取：https://platform.deepseek.com
- `DASHSCOPE_API_KEY`：通义千问（DashScope）的 API Key，用于 OCR 识别题目图片 + TTS 兜底，建议填。获取：https://bailian.console.aliyun.com 的 API-KEY
- `OPENAI_BASE_URL`：默认 https://api.deepseek.com，无需改

注意：两种配置方式二选一即可——填 `.env`，或在前端设置面板手动填 key（存在浏览器 localStorage）。

## 4. 启动

```bash
npm run dev
```

会同时启动：
- Express 后端，端口 3001
- Vite 前端，端口 5173

浏览器打开 http://localhost:5173

## 5. 验证部署成功

1. 后端健康检查：访问 http://localhost:3001/health ，应返回 JSON `{"status":"ok",...}`
2. 前端页面能打开 http://localhost:5173 ，且无红色报错
3. 在设置面板填入 key 后，随便上传一道题测试"生成"，能出视频预览说明全链路通

## 6. 使用流程

1. 上传题目图片（会 OCR 识别文字和公式，自动抠出插图）或直接粘贴题目文字
2. 在设置面板填 LLM key（DeepSeek）和 OCR key（DashScope），若已配 `.env` 可跳过
3. 点击"生成"：AI 走 4 段流水线（分析题目 → 生成脚本 → 审片 → 答案验证 → TTS 配音）
4. 预览、微调脚本、导出 MP4（保存在 `out/` 目录）

## 7. 单帧渲染验证（开发/排查用，重要）

需要验证动画、公式渲染、布局时，用 Remotion 渲染单帧截图，不要整个视频导出（太慢）。

```bash
cd 项目根目录
timeout 180 node node_modules/@remotion/cli/remotion-cli.js still src/index.ts ProblemExplainer verify.png --props=./anim-props.json --frame=310 --browser-executable="C:\\Program Files (x86)\\Microsoft\\Edge\\Application\\msedge.exe"
```

要点：
- composition ID 必须是 `ProblemExplainer`，不是别的
- `--browser-executable` 必须指定 Edge 路径，否则 Remotion 会去下载 113MB Chrome Headless，很慢甚至失败
- `--props` 传测试数据：`anim-props.json`（含跨场景曲线变形、参数动画、轨迹点三个动画）、`latex-props.json`（含中文下标公式 `\text{直}` 的 LaTeX 渲染测试）
- 改 `--frame` 渲染不同时间点：frame 310（曲线变形早期，应为紫色 V 形）、frame 500（轨迹点滑到 x 接近 0）、frame 600/760（参数动画振幅从 1 涨到 4.5）
- 在 Windows 的 bash 下，remotion 命令会自动后台化且 stdout 变 0 字节，务必用 `timeout N 命令 > 输出文件 2>&1` 重定向到文件再读结果

## 8. 打包发布

```bash
npm run build     # 构建前端 + Remotion bundle + Electron 主进程/预加载
npm run dist:win  # 打包 Windows 安装包，输出到 dist-app/*.exe
npm run dist:mac  # 打包 macOS 安装包
```

## 9. 常见坑（Agent 必读）

1. **渲染必须指定 Edge**：remotion still/render 不指定 `--browser-executable` 会卡在下载 Chrome。
2. **composition ID 是 ProblemExplainer**：写错 ID 会找不到 composition。
3. **LaTeX 公式**：讲解脚本里的公式建议用 `\(...\)` 包裹最稳妥；不包裹时系统会自动做"智能分段渲染"，含中文的裸公式（如 `B_{\text{直}} = \frac{\mu_0 I}{2\pi R}`）也能渲染成数学符号。如果看到公式显示为反斜杠源码，检查是不是改坏了 `src/components/blocks/theme.ts` 的 `renderMixedLatex`。
4. **图表克制**：AI 生成脚本时同一道题只应使用一个主要图形控件（数学题通常 plot 或 image），禁止各种图表（bar + plot + flow + table）轮流塞满。规则写在 `src/tools/visual-spec.txt`，改 prompt 也在那里。
5. **新增控件**：控件库是注册表驱动，新控件 = 写一个组件 + 在 `src/components/blocks/index.tsx` 的 `registerAllControls()` 里加一行注册，不要改 `MathTemplate.tsx` 的分发逻辑。注意 package.json 的 `sideEffects` 配置可能 tree-shake 掉注册副作用，注册必须包在 `registerAllControls()` 函数里。
6. **代码改动后**：跑 `npx tsc --noEmit` 确认类型无误；有存量错误在 GraphVisualizer/TimelineVisualizer 等旧文件，是历史遗留，不是本次改动的回归。

## 10. 关键文件速查

- 后端流水线：`src/server.ts`（4 阶段生成 + OCR + TTS）
- 视频模板：`src/templates/MathTemplate.tsx`（自由布局 + 时间轴驱动）
- 控件库：`src/components/blocks/`（registry.ts 注册表 + theme.ts 调色板/公式渲染）
- 函数曲线/柱状图：`src/components/visualizers/`
- LLM 输入规范：`src/tools/visual-spec.txt`、`json-schema.txt`、`spoken-guide.txt`
- 数据模型：`src/types/problem.ts`
- 测试数据：`anim-props.json`（三动画）、`latex-props.json`（LaTeX 渲染）
